# NEET Gemini Study Bot

Commands use the `ee` suffix as requested.

- /startee
- /helpee
- /quizee
- /assertionee
- /scoreee
- /leaderboardee
- /toptodayee
- /resettee
- /chatee
- /motivationee
- /winneree
- /mistakeee
- /mistakequizee
- /teachee
- /vivaee
- /planee
- /remindee
- /eli10ee
- /panicee
- /flashcardsee
- /survivalee
- /pdfsee
- /scheduleee
- /unscheduleee

Environment variables:
- TELEGRAM_BOT_TOKEN (or TELEGRAM_TOKEN)
- GEMINI_API_KEY
- ADMIN_IDS

Run:
python3 main.py
